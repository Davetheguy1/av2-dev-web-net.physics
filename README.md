# NET.Physics

Protótipo sem dependências de um serviço de locação de mídia física, feito com HTML, CSS e JavaScript puro.

Abra o arquivo `index.html` no navegador. Para usar a integração real com a TMDB, substitua `YOUR_TMDB_API_KEY` em `app.js` por uma chave criada no [portal de desenvolvedores da TMDB](https://developer.themoviedb.org/docs/getting-started).

As locações são salvas no `localStorage` do navegador. Em uma aplicação de produção, a chave da API deve ficar protegida no backend e as locações devem ser persistidas em um banco de dados.
